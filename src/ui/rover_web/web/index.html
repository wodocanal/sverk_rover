Журнал действий

Калибровка подключения моторов

Поднимите ровер так, чтобы все четыре колеса свободно вращались. Не держите его в руках. Остановите навигацию, патрулирование и любые внешние команды движения.

Каждый тест подает положительную команду только на один физический канал контроллера: 0,06 м/с, не более 2 секунд. Во время калибровки драйвер игнорирует обычные команды движения.

Проверка драйвера…

Канал 1 из 4

Смотрите на ровер сверху, его перед направлен от вас. «Вперед» означает, что это вращение катило бы ровер вперед по полу, а не «по часовой стрелке» с произвольной стороны.

Результат

    Результат сохраняется отдельно от исходников и переживает обновления кода. Порядок моторов и энкодеров применяется вместе при перезапуске bringup, не во время теста.

    Пока калибровка активна, движение заблокировано даже после закрытия вкладки. Короткий импульс остановится автоматически. После сохранения используйте перезапуск, а для отмены — «Завершить без применения».

    Подключение компонентов

    Мастер находит и проверяет Quad-MD, Yahboom YB-MRA02 и SLLIDAR/RPLIDAR. Камера, LED и другие периферийные устройства этим последовательным Device Manager не настраиваются.

    Сначала остановите аппаратный запуск. Веб должен работать отдельным сервисом rover-web.

    Ожидание…

    Подключите один компонент, выберите его роль и появившийся порт. Уже принятые компоненты оставляйте подключенными. Непроверенные порты не сохраняются.

    Подключенные порты

      Принятые в этом мастере

        Сохраненные устройства

          Старая конфигурация не меняется до сохранения. После сохранения запустите bringup: он создаст рабочие ссылки на устройства. Предыдущий конфиг остается в файле .json.bak.

          Конфигурация

          По умолчанию голос и Octoliner показываются по флагам запуска, а при отдельном запуске веба — по наличию нод в ROS. Ручной выбор сохраняется в этом браузере. Галочки не запускают и не останавливают ноды.

          Карта и навигация

          Изменяйте при выключенных SLAM и Nav2. Настройки сохраняются на ровере и применяются при следующем запуске. Они не меняют скорость ручного управления.

          Сканирование

          Меньше клетка — больше детализация, расход памяти и нагрузка. Старые карты сохраняют своё разрешение. По умолчанию: 5 см.

          Максимальные скорости

          Ускорение и торможение

          Достижение цели

          Драйвер моторов дополнительно ограничивает скорости и ускорения. Значения Nav2 не отменяют аппаратные ограничения. Без заднего хода отключается и восстановительный манёвр BackUp.

          Загрузка настроек…

          Подключение к серверу

          MQTT-связь с сервером команд, не API нейросети. Сохранение не прерывает связь; переподключение перезапускает только MQTT, без перезапуска bringup.

          Загрузка настроек…

          Пароль не отображается обратно и хранится на ровере в файле с правами 600. Используйте веб-интерфейс только в доверенной сети: HTTP и обычный MQTT не шифруют данные.
