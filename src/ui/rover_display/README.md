# rover_display

Полноэкранная Python/Tkinter-панель физического экрана. Это отдельное приложение,
не браузер и не копия веб-интерфейса.

## Запуск

```bash
ros2 launch rover_display display.launch.py
```

Нужны графическая сессия, `python3-tk`, доступ к DISPLAY/XAUTHORITY.
[config/display.yaml](config/display.yaml) по умолчанию использует `:0`,
`~/.Xauthority`, full_screen true и обновление раз в секунду.
Подключённый HDMI-дисплей без графической сессии недостаточен.

Профиль full запускает GUI внутри rover-bringup. rover-web.service его не
запускает. Отдельного rover-display.service нет; для headless-ровера задайте
`use_display:=false`. Escape закрывает окно.

## Что показывает

Верхняя строка: имя из robot_name_prefix/robot_serial и IP. Слева сеть,
hostname, ROS-граф, odom-позиция/курс/скорость, свежесть odom, CPU/RAM/диск,
температура, uptime. Консоль выполняет отдельные shell-команды пользователя
процесса с таймаутом, это не полноценный интерактивный PTY.

Правая панель по умолчанию `placeholder`. Режим `agent` показывает текст
из настроенного топика и индикатор батареи, без ввода сообщений агенту.

## Wi-Fi

Нажатие на IP открывает SSID/пароль и экранную клавиатуру. GUI вызывает
`/usr/local/sbin/rover-wifi-config.py`; исходник находится в
[tools](../../../tools/rover-wifi-config.py). Требуются отдельная установка
helper и узкое разрешение sudo. Установщик rover-bringup/rover-web не настраивает
эту Wi-Fi-функцию. Конфиг ориентирован на netplan и wlan0: не применяйте
без проверки сетевого менеджера конкретного образа.

## Ограничения текущей интеграции

- Имя экрана задаётся его собственным конфигом, не автоматически robot.id.
- agent_text_topic по умолчанию /agent/text, текущий агент отвечает в /agent/answer.
  Нужно согласовать имя и JSON-формат; панель сейчас выводит полученный текст.
- battery_topic ждёт sensor_msgs/BatteryState на /battery/state; база публикует
  Float32 /battery_voltage. Переименование топика не преобразует тип и не даёт процент.
- ROS «работает» означает доступность графа, не готовность всех датчиков.
- Настройки/новые страницы веба автоматически здесь не появляются.

GUI и его вспомогательные команды необходимо проверять в реальной desktop-сессии.
